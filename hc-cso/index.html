Hybrid HEFT + Cat Swarm Optimization (HC-CSO)

Menggabungkan heuristik deterministik Heterogeneous Earliest Finish Time (HEFT) sebagai warm-start populasi awal dengan Cat Swarm Optimization (CSO) yang dilengkapi Self-Motivated Inertia Weight (SMIW) untuk meminimalkan makespan penjadwalan task independen pada 16 VM heterogen.

Referensi Utama: Jai Bhagwan & Sanjeev Kumar (2021), “An HC-CSO Algorithm for Workflow Scheduling in Heterogeneous Cloud Computing System”, IJACSA Vol. 12, No. 6, pp. 484–492.

2. Cara Kerja HC-CSO & Self-Motivated Inertia Weight

Sinergi penjadwalan prioritas HEFT dengan perilaku eksplorasi lokal dan pergerakan terarah kawanan kucing.

  1. Fase 1 — Warm-Start HEFT: Seluruh task diurutkan berdasarkan ukuran instruksi (MI) terbesar terlebih dahulu (reduksi upward rank untuk task independen tanpa biaya komunikasi), lalu dipetakan ke VM dengan waktu selesai paling awal untuk membentuk Kucing #0 dan variasi swap Kucing #1..N.
  2. Fase 2 — Pembagian Mode via Mixing Ratio (MR): Pada setiap iterasi, sebagian kecil agen (proporsi MR ≈ 0.3) masuk ke Tracing Mode, sedangkan sisanya (1 - MR) menjalankan Seeking Mode.
  3. Fase 3 — Seeking Mode (Eksplorasi Lokal SMP): Setiap agen membangkitkan SMP kandidat mutasi mikro (memindahkan atau menukar task dari VM bottleneck ke VM paling ringan serta langkah memori pribadi fl = 0.5) dan memilih jadwal dengan makespan terkecil.
  4. Fase 4 — Tracing Mode & SMIW (γ): Agen bergerak menuju solusi terbaik global (X_best) menggunakan bobot inersia adaptif non-linear untuk mencegah velocity outrange:
γ(iter) = γ_max · exp(-c · (iter / maxIter)^c),   γ_max = 2.0, c = 2.0
V_{k,d} = clamp(γ · V_{k,d} + c1 · r1 · (X_{best,d} - X_{k,d}), -V_max, V_max)
X_{k,d}^{baru} = clamp(round(X_{k,d} + V_{k,d}), 0, nVMs - 1)
